# 인턴에서 CTO까지

AI 시대 개발자 커리어 시뮬레이션. 인턴으로 입사해 해마다 선택을 내리고, 능력치를 키우고, 이직하며 CTO를 노린다. 커리어를 가르는 건 결국 장애 대응이다. 새벽에 터진 장애를 잡으려면 감이 아니라 관측성이 필요하다. 어떤 관측 도구를 갖춘 회사에 있느냐에 따라 보이는 단서도, 고를 수 있는 선택지도 달라진다.

## 실행

```bash
npm i
npm run dev        # 개발 서버
npm test           # 테스트
npm run simulate   # 무작위 플레이 시뮬레이션 (엔딩 분포 확인)
```
